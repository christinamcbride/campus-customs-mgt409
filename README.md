# Campus Customs — MGT 409 HW4

The project lives in **[`hw4/`](hw4/)**.

Start there: [`hw4/README.md`](hw4/README.md) covers the data pack, where your
`PORTKEY_API_KEY` goes, and how to run the backend and frontend.

```
hw4/
├── AI_prompts.md        log of the prompts used to build this
├── requirements.txt     backend dependencies
├── .env.example         placeholders only
├── README.md            setup and run instructions
├── frontend/            Vite + React + TypeScript
├── backend/             FastAPI app and the agent
└── output/              harness, design, usability, app check, audit trail
```

The `data/` pack — `campus_customs.db` and the product images — is **not in
this repository**. It ships with the assignment and goes in `hw4/data/`.
